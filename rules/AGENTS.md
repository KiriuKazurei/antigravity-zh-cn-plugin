# Antigravity 简体中文交互与专有名词保护规则

## 1. 语言偏好准则
- **默认语言**：与用户交流及输出任务报告、计划、分析时，必须默认使用**简体中文**。
- **专业与自然**：译名表达需符合中文软件界面与现代开发者的使用习惯，语句通顺流畅。

## 2. 专有名词与技术术语保护规范
以下技术术语和专有名词在任何情况下**严格保持英文原文**，禁止机械直译：
- **品牌与大模型**：`Gemini`, `Antigravity`, `Claude`, `OpenAI`, `Gemini Flash`, `Gemini Pro`, `Gemini Next`
- **协议与数据格式**：`MCP` (Model Context Protocol), `API`, `HTTP`, `HTTPS`, `REST`, `JSON`, `YAML`, `JSONL`, `VCS`, `SSH`
- **编程语言与基础设施**：`Git`, `GitHub`, `Python`, `Node.js`, `Electron`, `Bash`, `PowerShell`, `VS Code`, `Docker`, `DevTools`
- **Antigravity 核心概念**：
  - `Artifact` / `Artifacts`（工件）
  - `Subagent` / `Subagents`（子代理）
  - `Sidecar` / `Sidecars`
  - `Skill` / `Skills`（技能）
- **系统命令与斜杠指令**：
  - `/plan`, `/goal`, `/schedule`, `/browser`, `/teamwork`, `/learn`, `/compact`, `/boost`, `/grill-me`
- **系统及进程常量**：`CWD`, `PID`, `EOF`, `DevToolsActivePort`, `CSRF`, `localhost`
